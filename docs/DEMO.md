# Защита ДЗ1 · 3 минуты

Перед входом в аудиторию: активировать `.venv`, создать `.env`, настроить сертификат, проверить `python main.py --check-connection` и `python -m pytest -q`. Включить демонстрацию терминала с крупным шрифтом. Все примеры работают на `data/sample_statement.csv`, а не на личной выписке.

## 0:00–0:50 · Реальная LLM и расчёт

```bash
python main.py --show-tools --message "Сколько я потратил на такси в октябре 2026?"
```

Ожидаемый результат: **600 ₽**. Код считает две операции (250 ₽ и 350 ₽). Указать на трассу: инструмент `get_spending_summary` выбрала GigaChat, сумму вычислил Python.

## 0:50–1:25 · Второй инструмент

```bash
python main.py --show-tools --message "Найди мои регулярные подписки и возможные дубли"
```

Ожидаются две серии: `Video Service` (299 ₽) и `Music Service` (129 ₽), плюс один потенциальный дубль. Трасса должна показывать `find_recurring_payments`.

## 1:25–2:05 · Ошибка инструмента, которую увидела реальная модель

```bash
python main.py --show-tools --fault-timeout get_spending_summary --message "Сколько я потратил на такси в октябре 2026?"
```

Три таймаута на уровне инструмента приводят к результату `error=timeout`. Граница ответственности: инструмент сообщает ошибку, агент должен честно сообщить о невозможности вычисления. **Здесь всё ещё настоящая GigaChat**, не готовая заранее реплика.

## 2:05–2:40 · Человек подтверждает действие

```bash
python main.py --show-tools --message "Найди подписку Video Service и пометь её к отмене"
```

Показать имя, сумму и ID перед подтверждением. При `n` пометка не появляется. При `y` появляется **только локальная** пометка. Не называйте это настоящей отменой подписки в банке.

## 2:40–3:00 · Тесты и журнал

```bash
python -m pytest -q
# Показать последние вызовы:
tail -n 8 logs/trace.jsonl
```

Автоматические тесты не используют оплачиваемый API. Повторяемость реальной модели оценивается отдельно:

```bash
python scripts/eval_live.py --runs 3
```

В случае сетевого `ReadTimeout` можно повторить живой запрос; таймаут LLM — не то же самое, что специально подставленный таймаут инструмента. Для быстрой защиты сначала проверь доступность API.
