# Тестирование и качество

Три слоя проверки из лекции 2: функции, сценарии с моделью и отказоустойчивость.

| Уровень | Проверка | Команда / критерий |
|---|---|---|
| 1 · Инструменты | Валидные суммы, неверные даты, категории, запрет чужого счёта, подписки и дубли | `python -m pytest -q` |
| 1 · Действия | Без `confirm` или после `n` нет изменений; с согласием отметка есть | unit-тесты `test_tools.py` |
| 1 · Ошибки | Три таймаута → структурированная ошибка, один таймаут → восстановление | unit-тесты `test_tools.py` |
| 2 · Цикл | Модель выбирает имя, результат возвращается в контекст, лимит шагов, защита от зацикливания | `test_agent_cycle.py` |
| 2 · Адаптер | Корректный GigaChat `FunctionCall` и `role=function`; схема проходит Pydantic SDK | `test_gigachat_adapter.py` |
| 2 · Живая LLM | Правильный инструмент и фактический числовой ответ, в том числе повторные прогоны | `python scripts/eval_live.py --runs 3` |
| 3 · Сбои | Таймаут `get_spending_summary`, отправленный реальной модели | `python main.py --fault-timeout get_spending_summary --message "Сколько я потратил на такси в октябре 2026?"` |

## Эталон синтетической выписки

| Вопрос | Проверяемая величина |
|---|---:|
| Траты на такси, октябрь 2026 | 600 ₽ (2 операции) |
| Траты на еду, октябрь 2026 | 1250 ₽ (2 операции) |
| Регулярные серии (три месяца) | Video Service 299 ₽; Music Service 129 ₽ |
| Возможные дубли | 1 группа (Cloud Provider 150 ₽, две записи) |
| Посторонний счёт | не показывать и не включать в расчёты |

**Метрики live-eval:** доля прогонов, в которых вызван правильный инструмент, и доля ответов, содержащих правильное значение. Одна и та же формулировка выполняется 3 раза из-за недетерминированности LLM. Никакие результаты заранее не заявляются: скрипт печатает фактическую оценку и создаёт JSONL-трассы.

## Что делать при ошибке

- `ModuleNotFoundError` → `python -m pip install -r requirements.txt` в правильной `.venv`.
- `ConnectError` / `ReadTimeout` → проверить интернет, сертификат, `GIGACHAT_TIMEOUT` и доступность API.
- `ModelNotSpecifiedError` → указать модель в `config.yaml`.
- `ValidationError` → проверить формат API-вызова; используется совместимый SDK `gigachat==0.2.4` и адаптер с `FunctionCall`.
- `401` → проверить Authorization Key и `GIGACHAT_SCOPE` без вывода ключа в терминал.

Логи `logs/` исключены из Git. На защиту нельзя использовать реальные клиентские банковские выписки и нельзя публиковать `.env`.
